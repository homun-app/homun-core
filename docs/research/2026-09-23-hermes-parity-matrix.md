# Hermes functional parity reference matrix — 2026-09-23

Reference: Nous Research Hermes Agent, pinned commit `c9dca726514b709cf6e677d236a79fc8d0627f37`. Source checkout was clean when the inventory was generated. This is a reproducible reference audit, not a runtime certification or completion claim.

## Goal and scope

Homun keeps its own engine and may derive/adapt upstream logic with attribution. No Hermes subprocess, Python-package import, service or runtime dependency is an acceptable substitute for the owned engine. External service integrations may still use their corresponding external services through Homun adapters.

Full engine parity includes context, control, tools, memory, skills, delegation, automation, providers, persistence and channel handling. Optional providers/integrations and non-engine surfaces (including skins/pets) remain explicitly tracked below; optional means selectable, not excluded. Surface/product equivalence can be delivered in Homun's conversational UX without copying Hermes branding or UI structure. No subset may be described as full parity.
