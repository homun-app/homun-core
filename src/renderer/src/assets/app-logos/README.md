# I loghi del catalogo app

Qui mette i loghi `scripts/aggiorna-catalogo-composio.mjs` (fase catalogo app,
P1): uno per app, `<slug>.svg|png|webp`, al massimo 200 KB, gli SVG ripuliti
(`<script>`, attributi `on*`, `href` esterni e `<foreignObject>` via). Il file
`src/shared/app-catalog/composio-catalog.json` porta il nome in `logo`.

Il catalogo di partenza nel repo è quello di PROVA con `logo: null`: i loghi
veri arrivano col lancio dello script con la chiave di progetto.
