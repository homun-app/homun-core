# Glossario italiano → inglese (fase 17a; esteso dalla 17c)

Le scelte fisse usate in TUTTO il catalogo `en`. Se serve una nuova parola
ricorrente, la si aggiunge qui prima di tradurla. Homun resta Homun.

| Italiano | Inglese |
|---|---|
| bot | bot |
| Bot principale / Principale | Main bot / Main |
| box, computer condiviso | computer, shared computer |
| Libreria | Library |
| Cassaforte | Vault |
| Routine | Routines |
| Aspetta te | Waiting for you |
| Connetti app | Connect apps |
| Revisione automatica | Auto-review |
| Modulo sicuro | Secure form |

Note di traduzione:

- I nomi delle lingue nel selettore (Italiano, English) NON si traducono.
- I nomi propri e i marchi non si traducono: Homun, Ollama, LM Studio, Docker,
  GitHub, Keychain, LaunchAgent, You.com, Exa, Tavily, Slack, ASPI, Vega-Lite,
  Mermaid, MCP, OAuth, CIMD/DCR.
- Gli identificativi tecnici restano: `mcp__<server>__<tool>`, `list-credentials`,
  `fill_credential`, `{{secret:NOME}}`, `idField`, `args`, i nomi dei tool.
- Il testo che arriva dal daemon (messaggi dei bot, descrizioni dei trigger in
  `cron-human`, riepiloghi delle card, regole auto-review proposte) NON è in
  questo catalogo: è la fase 17b.
