# Contratti condivisi

Qui verranno pubblicati OpenAPI e JSON Schema generati dal motore Python e versionati. Il client TypeScript sarà generato da questi contratti; Flutter potrà usare la stessa API.

La specifica iniziale è in `docs/specifications/04-api-client-rete.md`. I tipi del prototipo non sono ancora contratti del motore. Definire comandi, eventi, versioni, errori e ripresa dello stream nella fase F1 prima di generare client.
