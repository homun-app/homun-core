Homun provenance
Source: https://github.com/NousResearch/hermes-agent
Commit: c9dca726514b709cf6e677d236a79fc8d0627f37
native_prompt.py adapts execution guidance from agent/prompt_builder.py.
native_turn.py and application/agent_native.py reimplement canonical assistant/tool
history, request projection and persist-before-execute logic described in
agent/conversation_loop.py, agent/turn_request_assembly.py and agent/turn_tool_round.py.
Homun changes: scoped materials/tools, contribution-mediated questions, one pending
call per durable advance, existing authority/budget/review controls. No upstream
runtime dependency. This notice covers the derived portions, not all Homun code.

agent_control_history.py adapts interruption checkpoints and user correction
placement from agent/interrupt_control.py and conversation_loop.py. Homun uses
durable epochs/leases and explicit unknown outcomes in its own SQLite workflow.

context_plan.py derives rough multilingual token estimation and closed-exchange
context planning from agent/model_metadata.py and agent/context_compressor.py.
context_summary.py adapts the structured checkpoint prompt from the latter.
Homun preserves canonical history and stores separate hash-validated projections.

models/native_errors.py adapts the failure taxonomy of agent/error_classifier.py
and the Retry-After/jittered base-2 backoff of agent/retry_utils.py and
agent/turn_recovery.py (compute_error_backoff): statuses and well-known body
patterns map to a smaller Homun code set, raw provider bodies are never stored,
and provider-reported usage is carried on the typed failure when present.
application/agent_recovery.py adapts the retry placement of
agent/turn_api_error.py (three total attempts per phase, waits outside any
lease/transaction, corrections surviving backoff) onto Homun durable runs;
application/agent_run_failures.py keeps the shared terminal-failure fence.

Overflow recovery: application/agent_overflow.py and the forced context plan adapt
agent/turn_overflow.py at the same pinned Hermes commit. Homun retains explicit
window/output pins and durable authority/budget/control checks.
